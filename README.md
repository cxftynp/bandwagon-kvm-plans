## 两个页面上看不出来的限制：CPU 上限与 CN2 机房流量折算

搬瓦工对每档套餐的 CPU 占用有明确政策上限，常规方案迁入 CN2 线路机房后流量按三分之一计。这两条直接影响使用体验，但购物车页面基本不会主动提醒你。

### CPU 使用限制

按搬瓦工的使用政策，各档常规方案的 CPU 持续占用上限如下：

- 20G：1 核的 50%
- 40G：1 核的 75%
- 80G：1 核的 100%
- 160G：1 核的 100% 加第二核的 50%
- 320G：2 核的 100%
- 480G：3 核的 100%

这解释了 20G 方案为什么能压到每月 $4 出头：拿到手的是半核的持续算力。跑网站、脚本、轻容器没问题，持续跑编译、转码这类满载任务会撞上限。具体数值下单前以官方使用政策页面为准。

### 迁到 CN2 机房，流量按 1/3 算

常规方案购买时选的是普通机房，之后可以在 KiwiVM 面板里免费迁移。坑在这里：迁入 CN2 线路机房（比如洛杉矶 DC8、DC3）后，月流量按原额的三分之一计算。20G 方案的 1TB 会变成约 333GB，480G 的 6TB 变成 2TB。

周期越长单价越低。以 80G 为例，月付一年 $239.88，年付 $199.99，一年差约 $39.89；40G 的年付比两次半年付省 $5.99。唯一建议月付的情况，是你不确定项目能做多久。

**机房以后可以换吗？**

**能拿来跑 Docker 和代理工具吗？**
